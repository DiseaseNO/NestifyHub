# Nestify Hub

Samleapp for husholdet, til mobil.

## Hva appen skal gjøre

Samle det man ellers må lete etter på flere steder: lys og varme, strømforbruk, bilene,
handleliste, kalender, søppeltømming, oppgaver — og fantasyfotball.

**Foreløpig er den tom.** Skallet står klart; modulene kommer.

Kameraene har sin egen app og skal ikke inn her.

Appen er bare en klient. All logikk ligger på hjemmeserveren, og det finnes ingen
adresser, nøkler eller hemmeligheter i dette repoet.

---

Oppsett, bygging og drift er dokumentert internt, ikke her.
